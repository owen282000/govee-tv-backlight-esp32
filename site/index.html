Govee TV Backlight ESP32 installer

Flash the firmware that drives the Govee TV Backlight 3 Pro LED strip (H66A0, H66A1) to an ESP32, and set up Wi-Fi straight after. Version VERSION. Source and wiring on GitHub.

ESP32 dev board, over USB

Any ESP32 board with a USB port. Strip data on GPIO 16.

Your browser can't talk to USB devices. Use Chrome or Edge on a computer. The installer needs a secure page (https).

Gledopto GL-C-015WL-M, over USB

The same firmware with the Gledopto's output power switch (GPIO 18). Only if you have it on a USB-serial adapter.

Your browser can't talk to USB devices. Use Chrome or Edge on a computer. The installer needs a secure page (https).

Gledopto that still runs WLED, no cable

  1. Download govee-tv-backlight-gledopto-ota.bin from the latest release.
  2. In WLED open Config, Security & Updates, Manual OTA update and upload the file.
  3. The board restarts with its own Wi-Fi network govee-backlight-xxxx, password backlight. Join it with your phone: the setup page opens by itself, or go to http://192.168.4.1.
  4. Pick your Wi-Fi network, enter the password, save. The board restarts and joins it.

What happens

  1. Connect the ESP32 with a USB data cable and press the button. Pick its serial port.
  2. The installer erases the board and writes the firmware, about a minute. If it says Failed to initialize, hold the board's BOOT button while you click Install, and let go once the progress bar starts.
  3. It then asks for your Wi-Fi network and password, and shows the address of the board when it's connected.
  4. Open that address: /cmd?q=test runs a color test on the strip. The README has all commands and the Hyperion setup.

The installer runs in your browser with ESP Web Tools. Your Wi-Fi password goes from your browser to the ESP32 over USB and nowhere else.
